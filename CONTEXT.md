# Hatch

Local-first Windows task manager fronted by an always-on-top mascot for ≤4-second task capture. This glossary pins the canonical names for domain concepts; implementation facts live in `context/project-overview.md`.

## Language

**Summary**:
The launchpad page: an at-a-glance view of task state (Overdue / Completed today / Open counts, Today and Upcoming task rows) where every number and row is an entry point into the task it describes — never a read-only dashboard.
_Avoid_: Stats, dashboard, report
