Hatch

Local-first task manager for Windows. No account, no cloud, no telemetry.

1. Trust the signing certificate — first time only
  1. Download install-cert.cer
  2. Double-click it → Install Certificate → Local Machine
  3. Place in Trusted People → Finish
2. Install

Installing this way registers Hatch with Windows App Installer, which checks daily for new versions and updates in the background.

Install Hatch

Prefer a one-off install? Grab the .msixbundle from the latest release — but it won't update itself.
